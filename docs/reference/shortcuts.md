# Keyboard Shortcuts

CareKeeper supports standard iOS keyboard shortcuts when using an external keyboard with iPad. This reference lists all available shortcuts.

## Navigation Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘1` | Switch to Carees tab |
| `⌘,` | Open Settings |
| `⌘W` | Close current view/modal |
| `Esc` | Close current view/modal |

## List Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘N` | New caree (from caree list) |
| `⌘N` | New activity type (from caree detail) |
| `⌘F` | Focus search (if available) |
| `⌘R` | Refresh list (pull-to-refresh) |
| `↑` / `↓` | Navigate list items |
| `Return` | Select highlighted item |

## Editing Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘S` | Save current edit |
| `⌘.` | Cancel current edit |
| `⌘⌫` | Delete selected item |
| `Tab` | Next field |
| `⇧Tab` | Previous field |

## Activity Tracking Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘T` | Track new activity (from caree detail) |
| `⌘E` | Edit selected activity |
| `Space` | Toggle quantity field |
| `⌘Return` | Save and close |

## General iOS Shortcuts

These standard iOS shortcuts also work in CareKeeper:

| Shortcut | Action |
|----------|--------|
| `⌘Z` | Undo (text entry) |
| `⌘⇧Z` | Redo (text entry) |
| `⌘X` | Cut (text) |
| `⌘C` | Copy (text) |
| `⌘V` | Paste (text) |
| `⌘A` | Select all (text) |
| `⌘H` | Hide app |
| `⌘Q` | Quit app |

## Text Entry Shortcuts

When editing text fields:

| Shortcut | Action |
|----------|--------|
| `⌘B` | Bold (if rich text) |
| `⌘I` | Italic (if rich text) |
| `⌘U` | Underline (if rich text) |
| `⌘←` | Move to start of line |
| `⌘→` | Move to end of line |
| `⌥←` | Move word left |
| `⌥→` | Move word right |

## Form Navigation

When filling out forms (caree creation, activity tracking):

| Shortcut | Action |
|----------|--------|
| `Tab` | Next field |
| `⇧Tab` | Previous field |
| `Return` | Submit form (if on last field) |
| `⌘Return` | Force submit |
| `Esc` | Cancel |

## Accessibility Shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘⌥H` | Toggle VoiceOver |
| `⌘⌥=` | Increase text size |
| `⌘⌥-` | Decrease text size |

## Tips for Keyboard Users

### Quick Workflow

For efficient keyboard-only usage:

1. **Open CareKeeper**: `⌘1` (if already open)
2. **Select caree**: `↓` to navigate, `Return` to select
3. **Track activity**: `⌘N`, `Tab` through fields, `⌘Return` to save
4. **Back to list**: `⌘W`

### Number Pad Entry

When entering quantities:
- Focus quantity field with `Tab`
- Type number directly (decimal point supported)
- `Return` to confirm

### Date/Time Picker

When date picker is open:
- `↑`/`↓` to adjust selected component
- `Tab` to switch between date/time components
- `Return` to confirm

## Customization

CareKeeper uses standard iOS keyboard shortcuts and does not currently support custom keyboard shortcut configuration.

## Platform Availability

**Keyboard shortcuts are available on:**
- ✅ iPad with external keyboard
- ✅ Mac (if running via Mac Catalyst in future)

**Not available on:**
- ❌ iPhone (no external keyboard support)
- ❌ Apple Watch (no keyboard)
